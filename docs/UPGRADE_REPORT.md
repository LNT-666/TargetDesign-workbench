# 最新版本升级说明

> 注：bowtie2 与 casoffinder 两个脱靶搜索引擎已于 2026-09 下线，下文相关描述仅作历史记录。

本材料按日常使用流程整理，对比最早版本（`backup/step0_baseline`）与
最新版本的主要变化，供使用较早版本的同事快速了解。

## 1. 数据准备与基因序列提取

**旧版**：需要手动准备 GTF 和基因组 FASTA，提取主要围绕单个 motif
或简单区域。

**最新版**：
- 保留原有数据准备功能，支持下载基因组和注释、GTF 加 UTR 等预处理。
- 区域提取和 motif 提取并存。
- 新增多 target FASTA 直接输入，多个文件、多条序列都可以一次处理。
- 注释 GFF3 可以直接带入出库流程，结果中输出 `annotation` 和
  `nearest_tss` 两列。

## 2. Motif 提取

**旧版**：三个专用工具各自负责一种输入：
- Motif 分析：单个 motif + 方向 + 侧翼；
- 复杂 Motif：左右 motif + gap + 左右侧翼；
- Y/ZBP Motif：Y 序列 + 左右 motif + 距离范围。

**最新版**：三个工具的界面和输入方式不变，各自新增 **Library 出库**
按钮。提取结果会自动转成序列或查询 TSV，直接进入统一出库流程，不再
需要手工拼接后续步骤。

## 3. Guide 设计

**旧版**：没有独立的设计入口，主要靠提取后的 BLAST 和评分流程。

**最新版**：
- 新增自由 / 预设两种设计模式。
- 支持 Cas9、Cas12a/b、Cas14a、Cas13a/b/d、CRISPRi、TnpB 等系统，
  自动填写 spacer 长度、PAM、PAM 侧、seed 区间。
- 支持 motif overlap、GC 范围等过滤。

## 4. 脱靶搜索

**旧版**：只有 BLAST。

**最新版**：
- 新增本地精确搜索（exact），可在小基因组上穷举指定错配范围内的位点。
- 新增全基因组索引（indexed）：GRCh38 全基因组搜索已实测完成，
  2 个真实 guide 输出 12445 个命中，约 23 分钟，内存峰值约 11.9 GB，
  索引可复用，不再依赖 BLAST。
- 统一引擎接口：exact、BLAST、Bowtie2、Cas-OFFinder、GGGenome、
  indexed 可以切换，输出格式一致。

## 5. 评分

**旧版**：CFD 脱靶分数 + CROPSR 系数 + 启发式 on-target 分数。

**最新版**：
- 接入三个真实本地模型：CRISPR-M、DeepCRISPR、Azimuth，均有便携格式
  和回归验证。
- 非 Cas9 规则表：Cas12/13/14、CRISPRi、TnpB 的 PAM/PFS、seed、错配
  容忍、切割位点均带文献来源。
- Cas13 新增 RNA 评分：MFE、可及性、DR-spacer 相互作用、二级结构扰动。
- CRISPRi 新增 TSS 窗口、链方向、启动子区域评分。
- TnpB 新增离线 omegaRNA 规则，不再依赖在线 TEEP。

## 6. 批量出库

**旧版**：没有一键出库流程。

**最新版**：
- Library 一键出库：设计、脱靶和评分一次完成。
- 三种输入方式：BED 区域、多序列 FASTA、motif 查询 TSV。
- 可配置引擎、索引、BLAST db、模型、注释 GFF 等参数。
- 输出 `library_scores.tsv`、`top_offtargets.tsv` 等标准文件。

## 7. 界面与入口

**旧版**：三个独立 GUI + 主控制台。

**最新版**：
- 三个 GUI 保留原界面，增加 Library 出库按钮和“出库设置”对话框
  （引擎、索引、BLAST db、构建索引）。
- 主控制台 `python main.py` 直接打开统一工作台；原数据准备、模型下载等
  功能已并入 “Data prep / Models” 页签。
- 新增本机网页版：只监听 `127.0.0.1`，支持任务提交、进度、下载、
  失败重试，结果与桌面端一致。

## 8. 模型与测试

**旧版**：模型下载功能较基础，无统一状态和测试门禁。

**最新版**：
- 模型状态细分：未下载、不可加载、已加载、预测失败。
- 环境说明和模型清单文档完整。
- 一键回归测试 `python run_tests.py`，当前 81 项全部通过。

## 总结

对使用者来说，最直观的变化是：

- 脱靶搜索从“只能 BLAST”升级为“可本地穷尽搜索 / 全基因组索引搜索”；
- 评分从“启发式为主”升级为“真实模型 + 文献规则 + RNA 结构分数”；
- 从“手动串多个工具”升级为“三个 GUI 里直接一键出库”，一次得到评分、
  脱靶和汇总结果。
